BÀI THỰC HÀNH JAVASCRIPT — IMAGE PREVIEW

CÁCH CHẠY
1. Tải và giải nén toàn bộ file ZIP.
2. Mở thư mục image_hover_assignment bằng Visual Studio Code.
3. Mở index.html trong trình duyệt (hoặc dùng Live Server).
4. Rê chuột lên từng ảnh để xem khung preview thay đổi; đưa chuột ra khỏi ảnh để hoàn tác.
   Có thể dùng phím Tab để chuyển tiêu điểm tới ảnh.

CẤU TRÚC
- index.html: trang web và 4 ảnh có sự kiện mouseover/mouseout.
- style.css: bố cục và kiểu giao diện.
- script.js: hàm update() và undo().
- images/: các ảnh SVG nằm cục bộ trong gói, không cần tải ảnh riêng từ Internet.

ĐÃ THỂ HIỆN
- console.log() để kiểm tra sự kiện, alt và source.
- document.querySelector() / document.getElementById() để tìm phần tử #image.
- Cập nhật nội dung chữ và background-image.
- Hoàn tác về văn bản và hình nền ban đầu.
- Ảnh có alt, có thể điều khiển bằng bàn phím.

LƯU Ý
Nếu lớp yêu cầu dùng đúng file HTML mẫu được cấp, hãy đối chiếu tên ID và hàm sự kiện với mẫu đó trước khi nộp.
